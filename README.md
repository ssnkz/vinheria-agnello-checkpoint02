# Vinícola Agnello - Sistema de Cadastro de Vinhos

O projeto Vinícola Agnello é um sistema simples para cadastrar vinhos, armazenando informações como nome, tipo, safra (ano) e a quantidade no estoque.

Novas Implementações:
- Uso de Funções
- Uso de Whiles
- Uso de For
- Uso de Return
- Uso de Break
- Sistema de Cadastro, Venda, Ver Classificação, Ver Estoque, Ver Saldo Implementado.
